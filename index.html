й → ѷя → ѧе → ёє → ѥ п → ѱз → ꙃь → ъш → ѡ в → ѵа → ꙗм → ꙧі → і ї → їл → ꙥу → ꙋ (рідко)

Слова «привіт» і «народ» мають окремі форми: «ѱриѵітъ» та «народъ». Великі літери також перетворюються. Інші символи залишаються без змін.
